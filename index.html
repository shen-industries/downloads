Shen

A research IDE for scientists.

Shen is a local-first research app — an Integrated Research Environment, the research counterpart to a code IDE. One desktop window, three panels: your bibliography (Zotero), an editor (LaTeX / Python / text), and an AI assistant that answers from your own library.

The magic moment: a citation in an answer jumps straight to the exact PDF passage and highlights it, at the right spot on the page.

Installing

Three steps, whichever system you're on.

1 · Install

Linux — open the downloaded .deb or .rpm, then launch Shen from your applications menu.

macOS — open the .dmg and drag Shen into Applications.

2 · First launch on macOS

Shen isn't code-signed yet, so macOS blocks the first launch. Open System Settings → Privacy & Security and click Open Anyway. If that button doesn't appear:

xattr -dr com.apple.quarantine /Applications/Shen.app

3 · Add your API key

The assistant runs on Claude, so you bring your own key. It's stored in your OS keychain and never leaves your machine.

  1. Create one at console.anthropic.com — it looks like sk-ant-….
  2. In Shen: gear icon → paste the key → Save.
  3. When it reads Key configured, you're ready.
